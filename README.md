## 📖 Overview

**Expense-Tracker** is a feature-rich expense management application built with **JavaFX**, designed to simplify financial tracking through automated receipt scanning, AI-driven insights, and detailed reporting. Its modular architecture ensures seamless data flow between the UI, backend logic, and external services.

---

## ❓ Why Expense-Tracker?

🚀 **Receipt OCR**: Automatic data extraction from receipts using integrated OCR technology.
📊 **Expense & Category Management**: Easily add, update, and organize expenses and categories.
📂 **Data Persistence & Reports**: Reliable storage using DAO pattern and detailed financial reports.
🎨 **Themed UI**: Dynamic light/dark mode support for an enhanced user experience.
🤖 **AI Predictions**: Leverage AI for expense insights and forecasting.

## 🚀 Getting Started

### ✅ Prerequisites

This project requires the following dependencies:

* Programming Language: Java
* Package Manager: Maven

---

## ⚙️ Installation

Build Expense-Tracker from the source and install dependencies.

### 1. Clone the repository:

```bash
git clone https://github.com/Samarcodesinpython/Expense-Tracker
```

### 2. Navigate to the project directory:

```bash
cd Expense-Tracker
```

### 3. Install the dependencies:

Using Maven:

```bash
mvn install
```

---

## ▶️ Usage

Run the project with:

```bash
mvn exec:java
```

---

## 🧪 Testing

Expense-Tracker uses the **JUnit framework** for unit testing. Run all tests with:

```bash
mvn test
```
